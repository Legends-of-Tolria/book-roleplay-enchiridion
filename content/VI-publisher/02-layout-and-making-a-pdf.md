# Layout and Making a PDF

## Questions to ask yourself

1. Will people read it on screen, print it at home, or buy it printed?
2. How long is it: one page, a zine, a full book?
3. Do you want to learn a layout tool, or use a template?

## Technique: readable before pretty

Body text around 9 to 11 points, two columns for game books, plenty of margin, and headings people can scan. Fancy backgrounds come last, if at all.

## Technique: build a template once

Set your fonts, sizes, colours and page layout in one master document, then reuse it. Everything you make will look like it belongs together.

## Technique: export for the job

Screen PDFs want bookmarks, links and small file sizes. Print PDFs want bleed, high-resolution images and the printer's exact settings.
