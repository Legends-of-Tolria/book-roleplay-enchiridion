# Tools of the Trade

## Questions to ask yourself

1. Is this world for you alone, for a table of players, or for readers?
2. Do you need it offline, or on every device?
3. Will anyone else edit it?
4. Do you want to own the files, or is an online account fine?
5. What do you reach for most: words, maps or timelines?

If you answered "me alone, own the files", start with a vault. If you answered "a table of players, online", start with a campaign manager.

## Technique: start with one page

Write the world on a single page before you open any app: one paragraph of place, one of people, one of conflict, and three names you like. Move it into a tool once it outgrows the page.
