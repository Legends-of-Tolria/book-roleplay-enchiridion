# Appendix E: How to Contribute

This book is open. To suggest a tool, a prompt or a fix, open a pull request on the repository using the templates in `_templates/`.

Rules for a tool entry:

1. Link to the maker's own site, and open the link yourself first.
2. Give the cost as *free*, *free to start*, *one-time purchase* or *paid*.
3. One plain sentence on what it is for.
4. No affiliate or referral links.
