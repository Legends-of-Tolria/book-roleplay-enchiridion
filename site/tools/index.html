Small tools that do one job each. They run in your browser, nothing is installed, and your files never leave your computer.

File Converter

Turn Word documents, PDFs, Google Docs, web pages and text files into tidy Markdown notes, or into plain text or web pages.

Vault Primer

Set up a folder for your world, campaign or novel, with templates ready to use. Open it in Obsidian and start writing.

Table Roller

Paste any random table and roll on it, dice and all. Keep the ones you use every session.

Session Recap

Write up the session in a few minutes and get a vault note plus a post ready for your group's Discord.

Every tool here is open source, in this book's repository.
